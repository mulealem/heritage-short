.env secrets

GEMINI_API_KEY, CF_ACCOUNT_ID, CF_API_TOKEN. Gitignored; loaded by pipeline/common.py. Missing keys ⇒ that stage runs in mock mode.

runs.jsonl evidence

Every stage appends one line per model call (and notable op): model · params · seed · latency_ms · status · est cost. Graded logs live here, never in memory.

retries

pipeline/net.py: 3 attempts, exponential backoff on 429/5xx/timeouts. Errors logged, then the stage falls back — the pipeline never dead-ends.

② narration pipeline/narration.py

Gemini TTS · 130+ langs

  • one WAV per shot, style steered ("calm, warm")
  • fallback: tone @ exact duration
  • cache: sha256(text·lang·voice)

→ outputs/narration/<id>.wav

③ keyframes pipeline/keyframes.py

FLUX.1 schnell · Cloudflare

  • character/style sheet FIRST, then shots conditioned on it
  • fallback: placeholder PNG
  • cache: sha256(prompt·size·seed)

→ outputs/keyframes/<id>.png

④ moving shots pipeline/shots.py

Wan 2.2 TI2V-5B · Kaggle T4

  • emits manifest → Kaggle worker (save-as-you-go)
  • fallback: Ken Burns pan/zoom
  • mode decision recorded in plan.json

→ outputs/shots/<id>.mp4

caching

content-hash sidecars per artifact: change one shot in the storyboard → only that shot regenerates. Verified: full re-run = 100% cache hits. This is the walkthrough demo.

swappable models mp4 in = clip in

The video stage's contract is a file, not an API. Veo / Runway / Hunyuan clips drop in via tools/import_clips.py <folder> --model NAME → assemble normalises ratio, fps, length.
