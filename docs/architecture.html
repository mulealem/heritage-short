Heritage Short — Pipeline Architecture

a-video-generator · one contract, one command (make short), two renderers · Python stdlib + FFmpeg + a Rust comic renderer on CPU

hosted APIGPU on Kaggle (optional lane, not used in this film) local · CPUfile contract

.env secrets

GEMINI_API_KEY (narration), MINIMAX_API_KEY (images) — or IMAGE_PROVIDER=cloudflare with the two Cloudflare values for the free draft path. Gitignored. Asked for only when an asset is not cached: a clone that keeps outputs/ needs no keys at all.

runs.jsonl evidence

One line per call: stage · model · params · seed · latency_ms · status · est cost · output. COSTS.md is read from it, not remembered. The first 58 lines are the mock scaffold the project started from; everything after is real.

retries · fail loud

pipeline/net.py: 3 attempts, exponential backoff on 429/5xx/timeouts. Then the error is logged and the stage exits with instructions. No placeholder is ever written; finished work stays cached.

one command

make short — clone to both films. Measured on a clean clone with no keys: 0 model calls, 39 cache hits, 8 min 19 s, Rust build included.

story_brief.md the brief

story in five sentences · one picture per beat · audience · the feeling at the end. pipeline/script.py can draft a storyboard from it; this film's storyboard was written by hand against it.

▼  the other renderer — real moving shots, not used for this film (make film)

Real-only and untested end to end: no Wan clip was ever produced (F6). Clips from any generator drop in through tools/import_clips.py.

caching

Content-hash sidecars: the key is the sha256 of exactly what would be sent — provider, model token, composed prompt, reference, size, seed. Change one prompt → one model call and ten cache hits (measured). PROMPTS.md reports every asset as in sync or stale.

proven by cloning

A clean clone with no .env rebuilt both films: identical film.json, byte-identical audio, identical subtitles, 2,079 / 2,151 vertical frames bit-identical. That test found two bugs a cache-only run could not (F18, F19).

guards

The renderer refuses to run while a narration line was recorded from different text. make verify checks both films against the brief: streams, resolution, 60–90 s, subtitles.

swappable models a file is the contract

IMAGE_PROVIDER switches image models; the video stage's contract is one mp4 per shot id, so Wan / Hunyuan / hosted clips are consumed identically.
